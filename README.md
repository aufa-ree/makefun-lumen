Lumen — Keeper of the Last Light. A top-down arena survival game: sweep the lantern beam at the shadows, gather light shards, choose blessings as you level up, and survive 10 waves until dawn.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
